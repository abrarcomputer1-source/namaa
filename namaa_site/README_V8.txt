منصة نماء V8
=============

الجديد:
1) البيانات الأساسية والتكليف:
- رفع صورة أو PDF للتكليف.
- معاينة مرتبة داخل حساب المنسقة والمديرة.
- تنزيل المرفق مباشرة.
- المرفقات محفوظة في حاوية خاصة غير عامة.

2) الخطة الفصلية:
- تاريخ من / إلى لكل بند.
- ملاحظات لكل بند.
- رفع تقرير PDF مستقل لكل بند.
- تنزيل التقرير من حساب المنسقة والمديرة.

3) تحسينات إضافية:
- عرض أوضح لحالة الخطة والفترة الزمنية.
- بطاقات بيانات مرتبة في حساب المديرة.
- حد رفع 12MB للملفات الداخلية.

قبل رفع ملفات V8 إلى GitHub:
- شغّلي ملف upgrade_v8.sql مرة واحدة فقط داخل Supabase SQL Editor.

ثم ارفعي ملفات الموقع إلى مستودع GitHub بنفس الطريقة السابقة مع استبدال الملفات القديمة.

V8.1: أضيف زران لكل تقرير PDF في الخطة: معاينة التقرير + تنزيل التقرير. لا يحتاج هذا التحديث إلى SQL جديد.
